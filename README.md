### 1. 터미널 조작 로그 기록

| 명령어 | 설명 | 검증 방법 | 출력 결과 |
|--------|------|-----------|-----------|
| `pwd` | 현재 위치 확인 | 경로 출력 확인 | 입력 |
| `ls -a` | 목록 확인 (숨김 파일 포함) | 숨김 파일(`.`으로 시작) 포함 여부 | 입력 |
| `cd 폴더명` | 디렉토리 이동 | `pwd`로 이동 후 경로 확인 | 입력 |
| `mkdir 폴더명` | 디렉토리 생성 | `ls`로 생성 확인 | 입력 |
| `cp 파일1 파일2` | 파일 복사 | `ls`로 복사본 존재 확인 | 입력 |
| `mv 파일1 파일2` | 파일 이동/이름변경 | `ls`로 이름 변경 확인 | 입력 |
| `rm 파일명` | 파일 삭제 | `ls`로 삭제 확인 | 입력 |
| `cat 파일명` | 파일 내용 확인 | 내용 출력 확인 | 입력 |
| `touch 파일명` | 빈 파일 생성 | `ls -l`로 0byte 확인 | 입력 |

### 2. 권한 실습

#### 파일 권한 변경

| 단계 | 명령어 | 검증 방법 | 출력 결과 |
|------|--------|-----------|-----------|
| 변경 전 | `ls -l 파일명` | 권한 문자열 확인 | 입력 |

|------|--------|-----------|-----------|
| 변경 전 | `ls -l 디렉토리명` | 권한 문자열 확인 | 입력 |
| 권한 변경 | `chmod 755 디렉토리명` | 명령 실행 | 입력 |
| 변경 후 | `ls -l 디렉토리명` | 변경된 권한 문자열 확인 | 입력 |

### 4. Docker 기본 운영 명령

| 명령어 | 설명 | 검증 방법 | 출력 결과 |
|--------|------|-----------|-----------|
| `docker pull 이미지명` | 이미지 다운로드 | Pull complete 메시지 확인 | 입력 |
| `docker images` | 이미지 목록 확인 | 다운로드한 이미지 목록 확인 | 입력 |
| `docker ps` | 실행 중인 컨테이너 확인 | 실행 중 컨테이너 목록 확인 | 입력 |
| `docker ps -a` | 전체 컨테이너 목록 확인 | 중지된 컨테이너 포함 확인 | 입력 |
| `docker stop 컨테이너명` | 컨테이너 중지 | `docker ps`로 중지 확인 | 입력 |
| `docker logs 컨테이너명` | 로그 확인 | 로그 출력 확인 | 입력 |
| `docker stats` | 리소스 확인 | CPU/메모리 사용량 출력 확인 | 입력 |

### 5. 컨테이너 실행 실습

| 명령어 | 설명 | 검증 방법 | 출력 결과 |
|--------|------|-----------|-----------|
| `docker run hello-world` | hello-world 실행 | "Hello from Docker!" 메시지 확인 | 입력 |
| `docker run -it ubuntu bash` | ubuntu 컨테이너 진입 | 프롬프트 변경 확인 (`root@...`) | 입력 |
| `ls` | 컨테이너 내부 목록 확인 | 디렉토리 목록 출력 확인 | 입력 |
| `echo "hello"` | 컨테이너 내부 명령 수행 | "hello" 출력 확인 | 입력 |

#### attach vs exec 차이

| 구분 | attach | exec |
|------|--------|------|
| 용도 | 입력 | 입력 |
| 종료 시 컨테이너 상태 | 입력 | 입력 |
| 사용 상황 | 입력 | 입력 |
