## 2. 실행 환경
| 항목 | 내용 |
|------|------|
| OS | macOS (Darwin 24.6.0) |
| Shell | zsh |
| Terminal | macOS 기본 터미널 |
| Docker | 28.5.2 |
| Git | 2.53.0 |

#### 확인 명령어
```bash
uname -a       # OS 확인
echo $SHELL    # Shell 확인
docker --version  # Docker 버전 확인
git --version     # Git 버전 확인
```

### 1. 터미널 조작 로그 기록

| 명령어 | 설명 | 출력 결과 |
|--------|------|-----------|
| `pwd` | 현재 위치 확인 | 입력 |
| `ls -a` | 목록 확인 (숨김 파일 포함) | 입력 |
| `cd 폴더명` | 디렉토리 이동 | 입력 |
| `mkdir 폴더명` | 디렉토리 생성 | 입력 |
| `cp 파일1 파일2` | 파일 복사 | 입력 |
| `mv 파일1 파일2` | 파일 이동/이름변경 | 입력 |
| `rm 파일명` | 파일 삭제 | 입력 |
| `cat 파일명` | 파일 내용 확인 | 입력 |
| `touch 파일명` | 빈 파일 생성 | 입력 |

---

### 2. 권한 실습

#### 파일 권한 변경

| 단계 | 명령어 | 출력 결과 |
|------|--------|-----------|
| 변경 전 | `ls -l 파일명` | 입력 |
| 권한 변경 | `chmod 000 파일명` | 입력 |
| 변경 후 | `ls -l 파일명` | 입력 |

#### 디렉토리 권한 변경

| 단계 | 명령어 | 출력 결과 |
|------|--------|-----------|
| 변경 전 | `ls -l 디렉토리명` | 입력 |
| 권한 변경 | `chmod 755 디렉토리명` | 입력 |
| 변경 후 | `ls -l 디렉토리명` | 입력 |

### 4. Docker 기본 운영 명령

| 명령어 | 설명 | 출력 결과 |
|--------|------|-----------|
| `docker pull 이미지명` | 이미지 다운로드 | 입력 |

| `docker stop 컨테이너명` | 컨테이너 중지 | 입력 |
| `docker logs 컨테이너명` | 로그 확인 | 입력 |
| `docker stats` | 리소스 확인 | 입력 |

### 5. 컨테이너 실행 실습

| 명령어 | 설명 | 출력 결과 |
|--------|------|-----------|
| `docker run hello-world` | hello-world 실행 | 입력 |
| `docker run -it ubuntu bash` | ubuntu 컨테이너 진입 | 입력 |
| `ls` | 컨테이너 내부 목록 확인 | 입력 |
| `echo "hello"` | 컨테이너 내부 명령 수행 | 입력 |

#### attach vs exec 차이

| 구분 | attach | exec |
|------|--------|------|
| 용도 | 입력 | 입력 |
| 종료 시 컨테이너 상태 | 입력 | 입력 |
| 사용 상황 | 입력 | 입력 |

### 6. 커스텀 이미지 제작

#### 선택 방식
- [ ] (A) 웹 서버 베이스 이미지 활용
- [ ] (B) Linux 베이스 이미지 활용

#### 베이스 이미지 및 커스텀 포인트

| 항목 | 내용 | 목적 |
|------|------|------|
| 베이스 이미지 | 입력 | 입력 |
| 커스텀 포인트 1 | 입력 | 입력 |
| 커스텀 포인트 2 | 입력 | 입력 |
| 커스텀 포인트 3 | 입력 | 입력 |

#### 빌드 및 실행

| 명령어 | 설명 | 출력 결과 |
|--------|------|-----------|
| `docker build -t 이미지명 .` | 이미지 빌드 | 입력 |
| `docker run -p 포트:포트 이미지명` | 컨테이너 실행 | 입력 |
